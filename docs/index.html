// 01 · the console

Six modules, one offline binary

Every engine ships inside the package and runs on-device — parsing, hashing and rebuilding without ever opening a socket.

ARSENAL/00

Arsenal

The launch grid — sites, builds and crew, bundled so the whole operation opens from one cold-boot screen.

TOOLBOX/01

Toolbox

20 offline units — hashing, encoding, ciphers, keys and fingerprints, all through crypto.subtle, none of it leaving the device.

APK LAB/02

APK Lab

Open any .apk / .aab / .zip on the phone: decode binary AndroidManifest, resolve resources.arsc, disassemble every dex to smali, edit and repack — with alignment intact.

INTEGRITY/03

Integrity

The tamper detector. Reads the signing cert and schemes, cross-references loaded libs, and flags repacks, debug keys and injected mods — defensive by design.

SCANNER/04

Scanner

An on-device sweep of what's installed — packages, signers and native libs surfaced for inspection. Android only.

INTEL/05

Intel

Device facts and build telemetry — the ground truth the rest of the console reasons about, adapting per platform.

// 02 · beneath the webview

A native layer of its own

Where the JS engines stop, C++ takes over — a Dear ImGui surface compiled per ABI, and a VR-compatibility pass that gets headset games running on a flat screen.

native // libj3prefab.so

The prefab & movement panel

A drop-in Dear ImGui (1.92, GLES3) library: a prefab spawner and a touch flight-stick + look-pad, wired to your own game through a host callback. It owns no game state and hooks nothing — a modding SDK you compile in, not an injector.

compat // de-vr

Play VR APKs on a phone

Analyses a VR build across the four blockers — ABI, install gates, runtime and input — then patches the ones that keep an OpenXR/VrApi title from launching on a flat device or emulator, so you can actually run it.

No INTERNET permission. By design.

Every byte ships inside the package and the toolbox runs entirely on-device — the only permission it holds is VIBRATE. Real links are handed to the system browser through an intent that needs no permission at all. The result is a tool that literally cannot phone home. Built for tinkering, inspection and defense — entertainment and against-the-bad-guys use only.
